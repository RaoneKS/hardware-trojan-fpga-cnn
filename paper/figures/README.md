# Paper Figures

The paper uses two explanatory diagrams:

1. System architecture: MNIST input → Conv1/Pool1 → Conv2 Trojan sites → Pool2/FC/ArgMax → runtime detector and localization.
2. Detection flow: workload → cycle-accurate inference → invariant check → detector and region output.

The diagrams are conceptual architecture figures, not measurement plots. Numerical results remain in the manuscript tables and canonical evidence ledgers.
